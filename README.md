# Чат‑бот Max для управления задачами

Бот помогает создавать задачи, назначать ответственных, ставить сроки и получать напоминания.

## Как запустить

1. Установите зависимости: `pip install -r requirements.txt`.
2. Создайте файл `.env` со строкой `BOT_TOKEN=ваш_токен`.
3. Запустите: `python bot.py`.

## Команды бота

* `/start` — начать работу;
* `/tasks` — показать свои задачи;
* `/newtask` — инструкция по созданию задачи;
* `/task Название | Описание | @ответственный | дней` — создать задачу.
